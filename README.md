🇮🇹 [Italiano](#italiano) | 🇬🇧 [English](#english)

<a id="italiano"></a>

## 🇮🇹 Italiano

### 📄 Descrizione

Progetto realizzato per la materia **Inglese (madrelingua)**: una pagina di errore **404 "artistica"**, con testi in lingua inglese, ideata per la pasticceria **KiuGroove** ("Sweeter than sweets").

La pagina mostra:
- il logo KiuGroove, cliccabile, che porta alla home page del sito di gruppo;
- il titolo **"Error 404 - Page Not Found"**;
- un video meme in loop (avvio automatico, senza audio) dentro una cornice colorata;
- una frase ironica a tema torte e un link per tornare alla home page;
- un **conto alla rovescia di 30 secondi**, al termine del quale si viene reindirizzati automaticamente alla home page del sito di gruppo.

Inoltre, tramite JavaScript e CSS, la pagina disattiva il menu del tasto destro e il trascinamento delle immagini, e cerca di nascondere il pulsante di download del video. Il layout si adatta a schermi di diverse dimensioni grazie alle media query.

### 📁 Contenuto

| File | Descrizione |
|------|-------------|
| `index.html` | Struttura della pagina 404 |
| `style.css` | Stili della pagina, animazioni dei link e media query per tablet e smartphone |
| `script.js` | Conto alla rovescia con reindirizzamento alla home page, blocco del tasto destro e del trascinamento delle immagini |
| `video ridotto meme pagina 404.mp4` | Video meme mostrato nella pagina |
| `video intero meme pagina 404.mp4` | Versione completa del video meme (non usata direttamente dalla pagina) |
| `Logo KiuGroove senza sfondo.png` / `.psd` | Logo senza sfondo (usato nella pagina) e relativo file Photoshop |
| `Logo KiuGroove.png` / `.psd` | Logo con sfondo e relativo file Photoshop |
| `favicon.ico` / `favicon.png` / `favicon.psd` | Icona del sito (la pagina usa `favicon.ico`; i tre file contengono la stessa immagine PNG con estensioni diverse) |
| `.gitignore` | File e cartelle esclusi dal versionamento |

### 🛠️ Tecnologie utilizzate

- **HTML5** (inclusi i tag `<video>`)
- **CSS3** (flexbox, transizioni, media query)
- **JavaScript** (vanilla)
- Font **Montserrat** da Google Fonts; nell'`<head>` vengono caricati anche Ionicons e Font Awesome tramite CDN

### ▶️ Come aprirlo

Non serve nessuna installazione: basta scaricare (o clonare) la repository e aprire **`index.html`** con un qualsiasi browser moderno.

```bash
git clone https://github.com/MatteoMgr2008/Progetto-pagina-404-artistica-INGLESE-MADRELINGUA.git
```

**Nota:** serve una connessione a Internet per caricare il font da Google Fonts e per il link/reindirizzamento alla home page del sito di gruppo. I file `.psd` del logo si aprono con Adobe Photoshop (o un programma compatibile).

## 🇬🇧 English

### 📄 Description

Project made for the **English (native speaker)** school subject: an **"artistic" 404 error page**, written in English, designed for the **KiuGroove** pastry shop ("Sweeter than sweets").

The page shows:
- the KiuGroove logo, clickable, which links to the home page of the group website;
- the heading **"Error 404 - Page Not Found"**;
- a looping meme video (autoplay, muted) inside a coloured frame;
- a humorous cake-themed sentence and a link back to the home page;
- a **30-second countdown**, after which the visitor is automatically redirected to the home page of the group website.

Using JavaScript and CSS, the page also disables the right-click context menu and image dragging, and tries to hide the video download button. The layout adapts to different screen sizes through media queries.

### 📁 Contents

| File | Description |
|------|-------------|
| `index.html` | Structure of the 404 page |
| `style.css` | Page styles, link animations and media queries for tablets and smartphones |
| `script.js` | Countdown with redirect to the home page, right-click and image-drag blocking |
| `video ridotto meme pagina 404.mp4` | Meme video shown on the page |
| `video intero meme pagina 404.mp4` | Full version of the meme video (not used directly by the page) |
| `Logo KiuGroove senza sfondo.png` / `.psd` | Logo without background (used on the page) and its Photoshop file |
| `Logo KiuGroove.png` / `.psd` | Logo with background and its Photoshop file |
| `favicon.ico` / `favicon.png` / `favicon.psd` | Site icon (the page uses `favicon.ico`; the three files contain the same PNG image with different extensions) |
| `.gitignore` | Files and folders excluded from version control |

### 🛠️ Technologies used

- **HTML5** (including the `<video>` tag)
- **CSS3** (flexbox, transitions, media queries)
- **JavaScript** (vanilla)
- **Montserrat** font from Google Fonts; Ionicons and Font Awesome are also loaded via CDN in the `<head>`

### ▶️ How to open it

No installation needed: just download (or clone) the repository and open **`index.html`** in any modern browser.

```bash
git clone https://github.com/MatteoMgr2008/Progetto-pagina-404-artistica-INGLESE-MADRELINGUA.git
```

**Note:** an Internet connection is needed to load the Google Fonts font and for the link/redirect to the group website's home page. The logo `.psd` files can be opened with Adobe Photoshop (or a compatible program).
